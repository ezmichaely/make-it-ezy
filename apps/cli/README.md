# Make It Ezy CLI

Local-first capability discovery and planning for coding tasks.

Install the public CLI globally:

```bash
npm install --global make-it-ezy
ezy --help
```

Requires Node.js 20 or later. Run `ezy` from the project you want to analyze. See the [project README](https://github.com/ezmichaely/make-it-ezy#readme) for the workflow and examples.

The published package is self-contained: the internal `@make-it-ezy/core` workspace is bundled into the CLI and is not a separate npm install requirement.
