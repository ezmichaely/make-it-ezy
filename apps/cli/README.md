# Make It Ezy CLI

Local-first capability discovery and planning for coding tasks.

After the first public npm release, install globally:

```bash
npm install --global @make-it-ezy/cli
ezy --help
```

Requires Node.js 20 or later. Run `ezy` from the project you want to analyze. See the [project README](https://github.com/ezmichaely/make-it-ezy#quick-start) for the workflow and examples.
