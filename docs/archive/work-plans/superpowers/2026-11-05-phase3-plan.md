# Phase 3 `ezy plan` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `ezy plan "<outcome>" [--local-only]` that maps an outcome to capabilities + a minimum skill shortlist without installing.

**Architecture:** `extractCapabilities(outcome)` via a small lexicon → `planOutcome` runs `recommendSkills` per capability (or merged queries), merges/dedupes hits into Recommended/Optional/Not needed → `formatPlan` + CLI.

**Tech Stack:** TypeScript, pnpm, Vitest; reuse `recommendSkills` / `SearchOptions`.

**Spec:** `docs/superpowers/specs/2026-11-05-phase3-plan-design.md`

## Global Constraints

- Never installs or executes
- No LLM; lexicon + existing recommend heuristics only
- `--local-only` respected
- Exit 0 with empty skill matches; exit 1 only for missing outcome / unknown command
- Cap ~6–8 skills across buckets; Recommended 1–4

## Review Focus

- Empty outcome → CLI usage error
- Unknown outcome tokens → fallback capability from raw tokens + still searches
- Dedupes same skill across capabilities
- Video-ish / SaaS-ish lexicon hits produce expected capability labels
- Notes state discovery-only and Phase 4 for install/run
